# Winbox

**Your desktop, reimagined for the web — no installs, no limits, just open and go.**

🔗 **[Live Demo](https://winboxjs.github.io)**

A fully functional Windows 11-style web desktop environment that runs entirely in your browser. Winbox provides a familiar desktop experience with draggable, resizable windows and a suite of built-in applications.

## Features

- **Desktop Environment** — Full desktop with icons, taskbar, start menu, and live clock
- **Window Management** — Draggable, resizable, minimizable, and maximizable windows with focus handling
- **Built-in Apps**
  - 📝 **Notepad** — Create, open, edit, and save text files
  - 🧮 **Calculator** — Perform arithmetic with history display
  - 🌐 **Web Browser** — Browse the web with navigation controls and search
  - 📁 **File Explorer** — Navigate a virtual file system, create/delete files and folders
- **Virtual File System** — Persistent storage using `localStorage`
- **Session Persistence** — Open windows and their state are restored on reload
- **Custom Modals** — Native-style alert, confirm, and prompt dialogs
- **Responsive Design** — Adapts to small screens and touch devices
- **Zero Dependencies** — Pure HTML, CSS, and JavaScript in a single file

## Getting Started

Winbox requires no installation or build steps.

1. Clone the repository:
   ```bash
   git clone https://github.com/winboxjs/winboxjs.github.io.git
   ```
2. Open `index.html` in your browser.

That's it — Winbox runs entirely client-side.

## Usage

- **Open apps** — Double-click a desktop icon, click a taskbar button, or use the start menu
- **Move windows** — Drag the title bar
- **Resize windows** — Drag any window edge or corner
- **Maximize/minimize** — Use the window control buttons or double-click the title bar
- **Search apps** — Type in the start menu search box
- **Delete files** — Right-click a file or folder in File Explorer
